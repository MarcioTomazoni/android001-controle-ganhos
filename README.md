# 🚗 Android001 - Controle de Ganhos

Aplicativo Android desenvolvido para controle financeiro de motoristas parceiros.

## Objetivos

- Registrar corridas
- Registrar abastecimentos
- Calcular lucro líquido
- Gerar relatórios simples

## Tecnologias

- Android Studio
- Kotlin
- Material Design
- Git
- GitHub
